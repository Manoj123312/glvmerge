# Jira Project Setup and Sprint Plan

## Project
- **Project Name:** Client Management Application
- **Project Key:** CMA
- **Methodology:** Agile Scrum
- **Sprint Duration:** 2 Weeks

## Epics
1. **CMA-EPIC-1: Client Management**
   - Client creation
   - Client listing and basic profile view
2. **CMA-EPIC-2: Client Meetings**
   - Meeting scheduling
   - Meeting listing and status tracking

## User Stories
### Epic: Client Management
- **CMA-1** As an admin, I want to register a client so that I can maintain the client portfolio.
- **CMA-2** As an admin, I want to view all clients so that I can quickly reference client details.

### Epic: Client Meetings
- **CMA-3** As an admin, I want to schedule meetings so that client communication is organized.
- **CMA-4** As an admin, I want to view scheduled meetings so that I can track upcoming discussions.

## Sprint Backlog
- Setup Angular project and routing
- Build client registration UI
- Build meeting scheduling UI
- Add in-memory lists for clients and meetings
- Prepare MySQL schema for clients and meetings
- Write BDD scenarios in Gherkin
- Final review, build, and test run
